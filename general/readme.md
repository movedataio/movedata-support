# About MoveData

## Overview

MoveData is a [Salesforce AppExchange](https://appexchange.salesforce.com/appxListingDetail?listingId=a0N3u00000PFbeXEAT\&tab=r) application that streamlines the integration of fundraising platform data into Salesforce. The solution operates as a managed package, ensuring seamless compatibility with existing Salesforce environments.

## Key Features

* Data Integration: Connects fundraising platforms to Salesforce through API connections or supported file formats
* Automation: Enables automated transfer of fundraising data, reducing manual data entry
* Salesforce Compatibility: Functions as a managed package within Salesforce ecosystems
* Nonprofit Support: Compatible with both Nonprofit Success Pack (NPSP) and Salesforce Nonprofit Cloud (NPC) configurations
