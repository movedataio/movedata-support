# Deprecated Flow Components

The below list are components that have been deprecated within the NPSP Fundraising & Donations extension:\


* `ClearFieldFlowComponent`: Delete Field from Record
  * Moved to the MoveData Application Package\

* `ConvertToLocalDateFlowComponent`: Convert Date/Time to Date
  * Moved to the MoveData Application Package\

* `GetIdByKeyFlowComponent`: Dynamic Query By Key
  * No longer used; retained for customer extension flows\

* `GetRecordTypeComponent`: Record Type By Name
  * Moved to the MoveData Application Package\

* `GetRecordTypeNameComponent`: Record Type By ID
  * No longer used; retained for customer extension flows\

* `ProcessQuestionsFlowComponent`: Questions Helper
  * No longer used; retained for customer extension flows\

* `SetCurrencyValueFlowComponent`: Set Currency
  * Moved to the MoveData Application Package\

* `ToggleNpspTriggerFlowComponent`: NPSP Trigger Status
  * Scheduled for deletion\

* `TruncateStringFlowComponent`: Truncate String
  * Moved to the MoveData Application Package\

* `UpsertManagedFlowComponent`: Upsert Managed Output
  * Scheduled for deletion
