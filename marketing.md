# Marketing

{% hint style="info" %}
Metadata

* title=Commerce Schema Reference - Marketing
* entity=Marketing
* schema=Commerce
{% endhint %}

* `type`: Marketing platform type (e.g., "ga", "pixel")
* `source`: Traffic source (e.g., "google", "facebook", "newsletter") - equivalent to utm\_source
* `campaign`: Marketing campaign name or identifier - equivalent to utm\_campaign
* `medium`: Marketing medium (e.g., "cpc", "email", "social", "banner") - equivalent to utm\_medium
* `content`: Specific content or ad variant identifier - equivalent to utm\_content
* `term`: Search term or keyword that triggered the visit - equivalent to utm\_term
* `url`: Full URL that brought the user to the site
* `referrer`: HTTP referrer URL from the previous page
