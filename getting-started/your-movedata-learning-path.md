# Your MoveData Learning Path

## Introduction <a href="#introduction" id="introduction"></a>

MoveData is a powerful Salesforce integration platform that automates the flow of data from your fundraising platforms directly into Salesforce. Learning how it all works and fits together can be a daunting task. We have developed our knowledge base to help you with this journey and have below outlined the best way we believe you should go about learning all about MoveData and Salesforce.

We encourage you to follow the sequence outlined below as this will guide you through the basics of the underlying Salesforce platform as well as the MoveData solution.

## Learning Path and Resources <a href="#learning-path-and-resources" id="learning-path-and-resources"></a>

1. Learn the Basics of the Salesforce Platform
2. Learn the Basics of the MoveData Solution
3. Learn how to use the MoveData Solution
4. Learn how to configure the MoveData Solution
