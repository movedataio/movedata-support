# How to set State and Country Code for Address

{% hint style="info" %}
Metadata

* category=Technical
* tags=state,country,codes,contact,address
{% endhint %}

MoveData provides an ability to set State and Country Codes for contact addresses, which is easily configurable in your MoveData Settings.

If you do not see the necessary MoveData settings, please ensure your MoveData Extensions are updated to the latest version. Please see [Upgrading MoveData](../general/upgrading-movedata.md) for more information.

### Nonprofit Success Pack

{% embed url="https://app.arcade.software/share/qShKVpR6YIKwWICglZPY" %}

#### Transcription

* By default, MoveData will set the full State and Country name provided by the source platform
* To use State and Country Codes, open Settings
* Click Fundraising & Donations
* Set Use State Code for Address State to True
* Set Use Country Code for Address Country to True
* Click Update
* Go back to your notification and click Reprocess
* Observe that MoveData now sets the State and Country Code provided by the source platform

#### Transcription

* By default, MoveData will set the full State and Country name provided by the source platform
* To use State and Country Codes, open Settings
* Click General
* Set Use Country Code for Address Country to True
* Set Use State Code for Address State to True
* Click Update
* Go back to your notification and click Reprocess
* Observe that MoveData now sets the State and Country Code provided by the source platform
