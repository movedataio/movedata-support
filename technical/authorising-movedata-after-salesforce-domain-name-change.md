# Authorising MoveData after Salesforce Domain Name Change

Should you need to change your [Salesforce Domain Name](https://help.salesforce.com/s/articleView?id=000391121\&type=1), MoveData will need to be re-authorised to maintain connectivity with your Salesforce instance.

1. Log in to Salesforce as the user you want to authorise
2. Open MoveData from the App Launcher
3. Navigate to Settings tab
4. Click the "Authorise" button under the "Authorise MoveData" section

If you need to change the authorised user, please see [Change the MoveData Authorised User](https://support.movedata.io/knowledgebase/general/change-the-movedata-authorised-user/). Additional information about the authorised user is also available at [About the MoveData Authorised User](https://support.movedata.io/knowledgebase/general/about-the-movedata-authorised-user/).
