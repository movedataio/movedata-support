MoveData provides an ability to protect the campaign parent, which is easily configurable via "Protect Campaign Parent" campaign field.

{% embed url="https://app.arcade.software/share/fbH30hTzM4KlzUirVipA" %}

#### Transcription

* By default, MoveData will create campaigns provided by the source platform
* MoveData will set the Parent Campaign provided by the source platform
* Update Parent Campaign to the desired campaign you would like assigned
* Set Protect Campaign Parent to True. Note: Please ensure the Protect Campaign Parent field is added to the campaign page layout
* Click Save
* Go back to your notification and click Reprocess
* Observe that MoveData retains the Parent Campaign assigned
