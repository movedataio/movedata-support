### Required CSV Fields

<details>

<summary>These fields are required by MoveData to successfully process Much Loved CSV files</summary>

| Title                       | Description                                                |
| --------------------------- | ---------------------------------------------------------- |
| `Donation Id`               | Unique identifier for each donation transaction            |
| `Donation Date (UTC)`       | Date and time when the donation was made (in UTC timezone) |
| `Description`               | Details or notes about the donation                        |
| `Source`                    | Origin or channel through which the donation was received  |
| `Tributee First Name`       | First name of the person being honored/remembered          |
| `Tributee Family Name`      | Last name of the person being honored/remembered           |
| `Tribute`                   | Name or description of the tribute/memorial                |
| `Tribute Type`              | Category of tribute (e.g., in memory of, in honor of)      |
| `Tribute Create Date (UTC)` | Date when the tribute was created (in UTC timezone)        |
| `ID of Tributee`            | Unique identifier for the person being honored             |
| `ID of Tribute Guardian`    | Unique identifier for the tribute guardian/coordinator     |
| `Tribute Ref 3`             | Additional reference field for tribute tracking            |
| `Tribute Ref 4`             | Additional reference field for tribute tracking            |
| `Fundraising Ref 1`         | Reference field for fundraising campaign tracking          |
| `Fundraising Ref 2`         | Reference field for fundraising campaign tracking          |
| `Fundraising Ref 3`         | Reference field for fundraising campaign tracking          |
| `Fundraising Ref 4`         | Reference field for fundraising campaign tracking          |
| `Tribute ID`                | Unique identifier for the tribute                          |
| `External Page Url`         | URL link to external fundraising or tribute page           |
| `User ID`                   | Unique identifier for the user/account                     |
| `Guardian First Name`       | First name of the tribute guardian/family contact          |
| `Guardian Family Name`      | Last name of the tribute guardian/family contact           |
| `Guardian Email`            | Email address of the tribute guardian                      |
| `FC Title`                  | Title of the family contact (e.g., Mr., Mrs., Ms.)         |
| `FC First Name`             | First name of the family contact                           |
| `FC Family Name`            | Last name of the family contact                            |
| `FC Email`                  | Email address of the family contact                        |
| `FC Address 1`              | First line of family contact's address                     |
| `FC Address 2`              | Second line of family contact's address                    |
| `FC Address 3`              | Third line of family contact's address                     |
| `FC Town`                   | Town/city of family contact                                |
| `FC County`                 | County/state of family contact                             |
| `FC Postcode`               | Postal/ZIP code of family contact                          |
| `FC Country`                | Country of family contact                                  |
| `FC Telephone`              | Phone number of family contact                             |
| `FC Relationship`           | Relationship of family contact to tributee                 |
| `Donor ID`                  | Unique identifier for the donor                            |
| `From`                      | Name field indicating who the donation is from             |
| `Title`                     | Title of the donor (e.g., Mr., Mrs., Ms.)                  |
| `Donor First Name`          | First name of the person making the donation               |
| `Donor Family Name`         | Last name of the person making the donation                |
| `Donor Email`               | Email address of the donor                                 |
| `Tel`                       | Telephone number of the donor                              |
| `Address 1`                 | First line of donor's address                              |
| `Address 2`                 | Second line of donor's address                             |
| `Address 3`                 | Third line of donor's address                              |
| `Town`                      | Town/city of donor                                         |
| `County`                    | County/state of donor                                      |
| `Postcode`                  | Postal/ZIP code of donor                                   |
| `Country`                   | Country of donor                                           |
| `Donor Message`             | Personal message left by the donor                         |
| `User Ref 1`                | Custom reference field for user tracking                   |
| `User Ref 2`                | Custom reference field for user tracking                   |
| `User Ref 3`                | Custom reference field for user tracking                   |
| `User Ref 4`                | Custom reference field for user tracking                   |
| `GDPR Asked`                | Whether GDPR consent was requested                         |
| `Opt into Email`            | Donor's consent to receive email communications            |
| `Opt into Post`             | Donor's consent to receive postal communications           |
| `Opt into Phone`            | Donor's consent to receive phone communications            |
| `Opt into Text`             | Donor's consent to receive text/SMS communications         |
| `GDPR Capture Date`         | Date when GDPR consent was captured                        |
| `Donation`                  | Gross donation amount                                      |
| `Fee`                       | Processing or transaction fees                             |
| `Net`                       | Net donation amount after fees                             |
| `Gift Aid`                  | Gift Aid amount (UK tax relief scheme)                     |
| `Received`                  | Total amount received                                      |
| `Special Instructions`      | Additional instructions or notes for the donation          |
| `Offline GBP`               | Offline donation amount in British Pounds                  |
| `Offline EURO`              | Offline donation amount in Euros                           |
| `Offline USD`               | Offline donation amount in US Dollars                      |
| `Event ID`                  | Unique identifier for associated event                     |
| `Event Name`                | Name of the fundraising event                              |
| `Event Ref 1`               | Reference field for event tracking                         |
| `Event Ref 2`               | Reference field for event tracking                         |
| `Event Ref 3`               | Reference field for event tracking                         |
| `Event Ref 4`               | Reference field for event tracking                         |
| `Payment Status`            | Current status of the payment (e.g., completed, pending)   |
| `Paid On`                   | Date when payment was received                             |
| `Payment Ref.`              | Payment reference number or transaction ID                 |

</details>
